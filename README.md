# Tik0.Hub

Site web personnel tout-en-un : emplois du temps, messagerie, to-do list, ...

## ✨ Fonctionnalités

- **Emploi du temps Cours** : ouvre directement le portail ADE de l'université
- **Emploi du temps Entreprise** : ouvre le PDF du planning
- **Messagerie** : accès rapide à la messagerie (réservé au compte principal)
- **To-do list** : ajout / cochage / suppression de tâches, propre à chaque type de compte
- **Résumé des tâches** : mini-widget affiché en haut à gauche du menu, avec cases à cocher
